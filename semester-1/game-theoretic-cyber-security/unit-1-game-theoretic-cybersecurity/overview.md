# 📖 Overview

## 📖 Overview

In this unit, you will learn:

* The basic concepts and fundamentals of **Game Theory**.
* Why **Game Theory** is important in **Cyber Security**.
* How cyber security problems can be modeled as **strategic games**.
* The key components of a game, including **players, strategies, and payoffs**.
* The concept of **attacker–defender interactions** in cybersecurity.
* Different **game-theoretic models** used to analyze cybersecurity problems.
* Real-world applications of **Game Theory** in cyber defense and security decision-making.

> **Outcome:** By the end of this unit, you will have a strong foundation in Game Theory and understand how it is applied to solve cybersecurity challenges.
