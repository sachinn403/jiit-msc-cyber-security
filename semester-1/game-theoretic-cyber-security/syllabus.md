# 📜 Syllabus

## 📚 Syllabus

The **Computational Game-Theoretic Techniques for Cyber Security** course is organized into **five comprehensive units**, beginning with the foundations of game theory and gradually progressing toward advanced computational techniques and their practical applications in cybersecurity. The syllabus is designed to provide both theoretical understanding and problem-solving skills through mathematical models and real-world security scenarios.

***

### Unit 1: Game-Theoretic Cybersecurity

This unit introduces the relationship between game theory and cybersecurity.

#### Topics Covered

* Game-theoretic background for cybersecurity
* Types of game models applied to cybersecurity

***

### Unit 2: Fundamentals of Game Theory

This unit covers the core concepts and mathematical foundations of game theory.

#### Topics Covered

* Characteristics of games
* Game models
* Fundamentals of game theory
* Rules of game theory
* Pure strategy (Saddle Point)
* Two-person zero-sum games with saddle point

***

### Unit 3: Rule of Dominance and Mixed Strategies

This unit focuses on simplifying games and determining optimal strategies using dominance and mixed strategy techniques.

#### Topics Covered

* Reduction of games using the rule of dominance
* Two-person zero-sum games
* Matrix reduction by dominance
* Computation of mixed strategies

***

### Unit 4: Algebraic and Iterative Methods for Games

This unit explores various mathematical methods for solving game-theoretic problems.

#### Topics Covered

* Algebraic methods for determining optimum strategies and game value
* Methods of subgames
* Graphical methods for **2 × n** and **m × 2** games
* Solution of **3 × 3** and higher-order games
* Iterative methods for approximate solutions
* n-person zero-sum games
* Business applications of game theory (Bidding Problems)

***

### Unit 5: Game Theory Applications in Cyber Security

This unit demonstrates how game theory is applied to real-world cybersecurity challenges.

#### Topics Covered

* Introduction to cyber-attacks
* Basic network representation using graphs
* Cybersecurity as an attacker–defender game model
* Game-theoretic methods for cybersecurity applications
* Risk assessment for cybersecurity

***
