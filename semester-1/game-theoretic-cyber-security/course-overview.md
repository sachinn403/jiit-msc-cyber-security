# 📖 Course Overview

#### 🎮 Course Overview

* Understand the **fundamentals of Game Theory** and its key concepts.
* Learn how **strategic decision-making** is applied in cybersecurity.
* Study **pure strategies, mixed strategies, and zero-sum games**.
* Solve game-theoretic problems using **dominance, algebraic, and iterative methods**.
* Explore **attacker–defender game models** for cyber security.
* Apply game theory to **cyber-attacks, network security, and risk assessment**.
* Analyze real-world cybersecurity scenarios to determine **optimal defense strategies**.
