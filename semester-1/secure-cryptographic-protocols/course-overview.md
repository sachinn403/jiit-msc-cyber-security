# 📖 Course Overview

## 📖 Course Overview

### About the Course

**Foundations of Secure Cryptographic Protocols** is the first core cryptography course in the M.Sc. Cyber Security program. It introduces the concepts used to protect digital information and secure communication over modern networks.

In this course, you will understand how encryption works, how two systems securely exchange information, how users are authenticated, and how common security protocols protect data from attackers.

Instead of focusing only on theory, the course also explains how cryptography is used in real-world applications such as secure websites, online banking, messaging applications, cloud services, and enterprise networks.

***

### What You'll Learn

By the end of this course, you will understand:

* 🔐 How encryption protects data.
* 🔑 The difference between symmetric and public-key cryptography.
* 🤝 How secure key exchange and authentication work.
* 🌐 How protocols like TLS help secure internet communication.
* 🛡️ Common attacks against cryptographic systems and ways to prevent them.
* 🚀 Modern topics such as Zero Trust and post-quantum cryptography.

***

### Why This Course Matters

Almost every secure digital service relies on cryptography. Whether it's logging into a website, making an online payment, sending a message, or accessing cloud services, cryptographic protocols help keep information private and secure.

This course provides the foundation needed to understand, analyze, and build secure communication systems.
